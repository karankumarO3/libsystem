# 📚 LibSystem

LibSystem is a **Library Management System** developed to simplify the management of books, users, and library records through a web-based application.

## ✨ Features

* Book management
* User management
* Library record management
* Add, update, and delete records
* Admin functionality
* Database-driven system

## 🛠️ Technologies Used

* **PHP**
* **MySQL**
* **HTML**
* **CSS**
* **Bootstrap**
* **JavaScript**

## 🎯 Purpose

This project was created to gain practical experience in developing database-driven web applications and working with PHP and MySQL.

## 💻 Running the Project

The project is designed to run locally using **XAMPP** with Apache and MySQL.

> This project was developed for local use and learning purposes.
